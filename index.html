📄 Journal Papers

2025
DeepGuard: Enhancing Violence Detection in Smart Cities Through Deep Learning
Md. Al-Mamun Provath, M. Rahman, Kaushik Deb, Pranab Kumar Dhar, Tetsuya Shimamura
IEEE Access (IF: 3.9)
Introduced DeepGuard, a comprehensive system for video violence detection in smart cities, with particular focus on political violence. Achieved 92.86% accuracy with just 1.9M parameters using fine-tuned MoViNet-A0 and custom keyframe extraction.
2025
CAMFusion: Context-Aware Multi-Modal Fusion Framework for Detecting Sarcasm and Humor
M. Rahman, Md. Al-Mamun Provath, Kaushik Deb, Pranab Kumar Dhar, Tetsuya Shimamura
IEEE Access (IF: 3.9)
Presented CAMFusion, a context-aware multi-modal fusion framework for detecting sarcasm and humor in Bangla videos. Achieved 90% accuracy by integrating visual features with textual features processed via BiLSTM and GRU.
2023

Md. Al-Mamun Provath, Kaushik Deb, Pranab Kumar Dhar, Tetsuya Shimamura
IEEE Access (IF: 3.9)
Developed a global context attention-guided CNN that significantly improved cancer classification accuracy while reducing computational costs, making the model highly suitable for mobile deployment.
